> 映射曲线和 CO2 阈值必须实测才能定,定型后再转 PCB。

## 一、先做一个决定:色温传感器选谁

| | TCS34725 | AS7341 |
|---|---|---|
| 通道 | RGB + Clear(4 通道宽带) | 8 个窄带 + Clear + NIR + 闪烁检测 |
| 模块价 | ¥12–25 | ¥45–90 |
| ESPHome | 原生支持 | 原生支持(2023.3.0 起) |
| I2C 地址 | 0x29 | 0x39 |
| 算 CCT 的方式 | RGB → McCamy 经验公式 | 光谱形状直接拟合 |
| 实测精度 | 日光尚可;LED/荧光灯下社区实测有 6490K 读成 11000K+ 的案例 | 显著更准,且能区分晴天/阴天/黄昏的光谱形状 |

**建议买 AS7341。** 差价只有 ¥40–60、一次性,而这条线的全部价值就压在"窗外日光的
色温判断准不准"上。用 TCS34725 省 ¥50,然后发现映射曲线怎么调都对不上,是最亏的。

**更稳的做法:两个都买**(合计不到 ¥100)。两者 I2C 地址不冲突,原型阶段并排挂在同
一条总线上跑一周,直接看谁的读数跟窗外实际光线对得上 —— 这正是"先原型后画板"要
换来的东西。定板时只留胜出的那颗。

## 三、下单前必须知道的三个坑

1. **SCD41 的供电会把 XIAO 拖重启。**
   SCD41 测量瞬间吃约 205mA;XIAO 的 3.3V LDO 同时还要供 WiFi 发射峰值,容易掉压
   复位。做法:模块走 XIAO 的 **5V 脚**供电(模块自带稳压),并在模块电源脚并一颗
   100–470µF 电解(即 C4)。

2. **自动自校准(ASC)必须关掉 —— 这条对你家尤其要命。**
   SCD41 出厂默认开 ASC,它假设传感器每周至少见一次约 420ppm 的室外空气,并拿那个
   最低值当零点。你家**全屋只有一扇窗**,卧室和客厅靠里的两个节点长期见不到真正的
   室外空气,ASC 会把偏高的基线当成零点,读数越漂越低 —— 越缺氧显示得越正常。
   固件里设 `automatic_self_calibration: false`,装机后把传感器拿到室外通风处
   (避开车流)放 5 分钟,触发一次 forced calibration 到 420ppm。**这条要转告主群
   写固件的 session。**

3. **色温模块板载的白光 LED 要关。**
   TCS34725 的常见模块(GY-33 等)板上带一颗白光 LED,不关就是自己照自己,读数全废。
   AS7341 模块也常带 LED 驱动脚。到货第一件事:确认跳线/焊盘位置并关掉。

## 四、顺带一条设计上的便宜

窗边节点开窗时 CO2 会掉向室外值,这跟门磁的开合信号天然互为印证。固件里可以拿
"CO2 骤降"给门磁做交叉校验(磁铁掉了、门磁老化的时候还能兜住),不额外花钱。
