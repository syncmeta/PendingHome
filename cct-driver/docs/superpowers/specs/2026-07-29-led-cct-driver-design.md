# 6 路 CCT 灯带 ESPHome 驱动板 — 设计文档 v2

日期:2026-07-29(v2,吸收 QuinLED/商用控制器/开源项目对照研究)
状态:待用户批准

## 1. 目标与范围

一块定制 PCB,基于 ESP32 + ESPHome,独立控制 **6 条 24V CCT(双色温)灯带**,每条 2 个 PWM 通道(暖白 + 冷白),共 **12 路 PWM**。总线按 **12A @ 24V(288W)** 设计,单通道按 **最大 3A** 设计。接入用户现有 Home Assistant(T630 部署)。

范围内:PCB 原理图/布局、完整 BOM(全部立创商城)、ESPHome 配置。
范围外:远端传感器节点(§9)、外壳。

## 3. 电流预算逻辑(v2 明确)

CCT 灯带标称功率为两通道**合计**。ESPHome `cwww` 平台开 `constant_brightness: true` 后 CW+WW 合计 duty ≤100%,即**每条灯带平均电流 ≤ 单通道满载 3A**。因此:

- 正常模式(constant_brightness on):6 条 × ≤3A = 最坏 18A,仍可能超 12A 总设计 → **固件用 INA226 做总功率软限制**(超限降亮度并上报 HA);
- 若关掉 constant_brightness:理论最坏 36A → 由 15A 主保险丝硬兜底;
- 硬件选型(MOSFET/端子/走线)按每通道 3A 连续、每条灯带正极 3A 连续、母线 12A 连续,均留余量。

## 4. 系统架构

```
24V DC 输入 (LRS-350-24)
   │
   ├─ 15A ATO 片式保险丝 ─ AO4407A P-MOS 防反接 ─┬─ 输入 TVS(SMBJ26A) + 电解 ≥470µF/50V
   │                                             ├─ INA226 + 2mΩ 高边采样 ─► 24V 主母线
   │                                             │      ├─► 6× 输出 V+ (各经 5A 2920 自恢复保险丝 + 本地去耦)
   │                                             │      └─► 12× AOD4184A 低边开关 ◄─ 灯带 CW/WW 负极
   │                                             │           (每路: 100Ω 栅阻 + 10k 下拉 + SS34 续流 + SMBJ26A)
   │                                             └─ 0.75A PTC ─ XL1509-5.0 (24V→5V) ─ AMS1117-3.3
   │                                                              │5V: CH340C/UART传感器/HCT245    │3.3V: ESP32/INA226/温感/I2C
ESP32-WROOM-32E (兼容 32UE 焊盘, BOM 二选一切外置天线)
   ├─ 12× LEDC PWM ─► 74HCT245 ×2 (/OE 上电高阻) ─► 栅极 + 12× 通道指示 LED
   ├─ I2C ─► INA226 + LM75 类温感(MOSFET 区) + XH2.54 + Qwiic(JST-SH) 座
   ├─ UART2 ─► XH2.54 (5V 供电, 兼容 LD2410)
   ├─ 4× 干接点输入 (10k 上拉 + RC 消抖)
   └─ UART0 ─► CH340C(+USBLC6-2 ESD) ─► USB Type-C (CC 5.1k×2, 自动下载)
```

接法:灯带共阳,低边斩负极。每条灯带一个 3 位插拔端子:V+ / CW / WW。

## 6. 关键电路设计

### 6.1 功率级(×12)
- **AOD4184A**(40V/50A,TO-252,Rds(on) ≤9.5mΩ @ Vgs=4.5V 手册保证):3A 导通损耗 <0.03W。40V 耐压对 24V 母线余量充足(v1 的 30V 管余量不足,已按 QuinLED 实践修正)。
- 栅极:100Ω 串阻(有意放缓边沿抗 EMI,QuinLED 思路)+ 10k 栅源下拉(上电防浮空)。
- **每路 SS34 续流二极管**(漏极→V+,吸收长灯带线感抗关断尖峰)+ SMBJ26A TVS(钳位 42.1V < 40V 管的雪崩区,双保险)。
- 每路 V+ 串 SHV2920P500-30 自恢复保险丝;输出端子旁本地去耦(电解 + MLCC)。
- 每路一颗指示 LED 接 HCT245 输出侧(不碰功率级),调试直观。
- 12 路 CW/WW 成对相位错开(LEDC 支持),电源纹波电流减半。

### 6.2 输入保护(三级保险结构)
- 主路:15A ATO 汽车片式保险丝(板载保险丝夹,手焊)→ AO4407A P-MOS 防反接(栅极 12V 稳压管 + 100k 钳位)。
- 输入 TVS SMBJ26A + 电解 ≥470µF/50V(QuinLED "重去耦"实践)。
- 逻辑支路:独立 0.75A PTC 自恢复保险(与 LED 主路分开,逻辑电源故障不牵连主路)。

### 6.3 电平转换
- 74HCT245PW ×2,5V 供电,TTL 门限接受 3.3V 输入;/OE 并联接 GPIO15(10k 上拉)。
- AOD4184A Qg≈14nC@4.5V,19.5kHz 下平均栅流 <0.3mA/路,HCT245 直驱无压力。

### 6.4 功率监测与温度
- INA226 + 2mΩ/2W/2512,高边接于防反接之后总母线;12A 时压降 24mV、耗 0.29W,满量程 40.96A。
- **板载 I2C 温感(LM75B 类)置于 MOSFET 区**,固件做过热降额(QuinLED 实践)。

### 6.5 USB 与电源链
- Type-C(16P)+ CC1/CC2 各 5.1k 下拉(开源板高频翻车点,重点检查项)+ **USBLC6-2 ESD 阵列**;CH340C + S8050×2 自动下载。
- XL1509-5.0(40V 耐压 150kHz)→ 5V:布局按 datasheet 最小环路,电感 33µH 饱和电流 ≥2A;AMS1117 → 3.3V(WiFi 突发预算 ≥600mA)。

### 6.6 传感器与开关接口
- I2C:1× XH2.54-4P + 1× **Qwiic(JST-SH 1.0mm 4P)**,兼容市售传感器模块生态;仅限板边短线 <1m。
- UART2:1× XH2.54-4P(5V/GND/TX/RX,LD2410 直插;直通线束注意 TX/RX 交叉)。
- 干接点:KF128-2.54-5P,每路 10k 上拉 + RC 消抖(100nF+1k)。

### 6.7 WiFi 天线
- 布 WROOM-32E/32UE 兼容焊盘,BOM 二选一:塑料盒用 32E 板载天线,金属箱换 32UE + IPEX 外置天线(社区实测金属盒内差 20dB)。天线区按乐鑫要求禁铜,模组置板边、远离功率区。

## 7. 布局要点

- 2oz 铜;24V/GND 双面大面积覆铜,MOSFET 漏极焊盘过孔阵列到背面覆铜散热(QuinLED "铜面即散热片")。
- 大电流走线开窗堆锡;功率区与 ESP32/模拟区分区,INA226 采样走线开尔文连接。
- 丝印直接印接线图:每端子标 "CH1 V+/CW/WW"、"24V IN MAX 12A"、输入极性;测试点:每路栅极/漏极 + 3V3/5V/GND 测试环。
- 板约 13×10cm,四角 M3 孔。

## 9. ESPHome 配置要点

- 12× `ledc` @19531Hz(12-bit),CW/WW 成对 `phase_angle` 错开 180°。
- 6× `cwww`,**`constant_brightness: true`**(防灯带双通道同满载超额定)。
- INA226 总功率软限制:超 288W 触发全局降亮度 + HA 告警;`wifi_signal` 传感器随配(诊断金属盒信号)。
- LM75 温感 → 过热(如 >80℃)自动降功率。
- 低亮度调光:`gamma_correct` 默认 2.8,台阶感明显时降 2.2;output 设 `min_power` + `zero_means_zero`;规格诚实标注 ~1000:1 调光比(最低几级 duty 受开关沿限制不保真)。
- PWM 频率预设注释:日常 9765Hz/13bit、拍视频 39062Hz/11bit(QuinLED 档位),默认 19531Hz。
- 4× `binary_sensor` 干接点:单击开关、长按调光。
- GPIO15 boot 脚本拉低使能 HCT245;UART2 预留 `ld2410`。
- ESPHome YAML 随硬件工程一起入库发布(开源社区实践)。

## 10. 配套建议(范围外)

远端传感器每点位独立节点:ESP32-C3 核心板(~¥10,够用)或立创 ESP32-S3R8N8 开发板(~¥33,带原生 USB,豪华版),WiFi 直连 HA。本板 UART/I2C 只服务板边传感器。

## 11. 验证计划

1. 首批贴 2 片;上电前万用表查 24V/5V/3.3V 轨短路。
2. 空载上电:三轨电压 → USB 识别(重点验 CC 下拉:用 C-to-C 线测)→ 刷 ESPHome → WiFi → INA226/LM75 读数。
3. 单条灯带:调光/色温曲线、低亮度台阶感、MOSFET 温升、无可闻噪声、手机高快门拍摄无条纹。
4. 满载(6 条或电子负载 12A):采样电阻/防反管/走线温升,INA226 对钳流表校准,功率软限制触发测试。
5. 关断尖峰:示波器看长线(5m+)灯带关断时漏极电压,确认 <40V。
6. 干接点、UART/I2C、上电无闪光(反复上下电 10 次)逐一验证。
7. 通过 → 补贴 3 片;有改版 → 修版再议。

## 附:对照研究结论摘要

- QuinLED(行业标杆):架构同构(低边 + 缓冲驱动 + 每路熔断 + 温感);我们的 INA226 是其没有的超越点;30V 管余量不足是其明确踩过的坑 → 已改 40V。
- 商用板(H801/MagicHome/Shelly RGBW2):≤1kHz PWM、无保险丝、无监测、上电闪光 → 我们逐项规避;19531Hz 与 WLED ESP32 默认一致。
- 开源社区(oshwhub/GitHub):12 路 + 24V + 电流监测属空白;每路指示灯、丝印接线图、Qwiic、测试点为高频最佳实践 → 已吸收。
