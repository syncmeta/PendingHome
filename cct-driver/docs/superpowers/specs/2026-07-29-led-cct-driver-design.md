# 6 路 CCT 灯带 ESPHome 驱动板 — 设计文档

日期:2026-07-29
状态:待用户批准

## 1. 目标与范围

一块定制 PCB,基于 ESP32 + ESPHome,独立控制 **6 条 24V CCT(双色温)灯带**,每条灯带 2 个 PWM 通道(暖白 + 冷白),共 **12 路 PWM**。总线按 **12A @ 24V(288W)** 设计,单路按 **最大 3A** 设计。接入用户现有的 Home Assistant(T630 部署)。

范围内:PCB 原理图/布局、完整 BOM(全部立创商城采购)、ESPHome 配置。
范围外:远端传感器节点(见 §9 配套建议)、外壳。

## 2. 已确认的需求决策

| 决策点 | 结论 |
|---|---|
| 通道数 | 6 条 CCT 独立控制 = 12 路 PWM |
| 制作方式 | 定制 PCB,嘉立创 2 层板 + 经济 SMT 贴片,插件自己焊 |
| 电源 | 外置明纬 LRS-350-24(350W/14.6A),板载只接 24V DC |
| 安装 | 墙面/洞洞板固定,四角安装孔,不做导轨/吊顶适配 |
| 端子 | 混用:输入大电流栅栏端子,输出 3.81mm 插拔式 |
| MOSFET 驱动 | 74HCT245 电平转换(3.3V→5V)+ 逻辑电平 NMOS,PWM 19.5kHz 无频闪 |
| 附加功能 | USB-C 调试口(CH340C)、INA226 总线功率监测、4 路墙壁开关干接点输入、板边传感器接口 |
| 传感器布局 | 分散在房间各处 → 板上只留精简接口(1×UART + 2×I2C),远端用独立 C3 节点 |
| 生产数量 | PCB 5 片;建议先贴 2 片验证,再补贴 3 片 |

## 3. 系统架构

```
24V DC 输入 (LRS-350-24)
   │
   ├─ 15A 汽车片式保险丝 ─ AO4407A P-MOS 防反接 ─┬─ INA226 + 2mΩ 采样 ─► 24V 主母线
   │                                             │        │
   │                                             │        ├─► 6× 输出端子 V+ (每路经 5A 2920 自恢复保险丝)
   │                                             │        └─► 12× NCE3080K 低边开关 ◄─ 灯带 CW/WW 负极
   │                                             │
   └────────────────────── XL1509-5.0 (24V→5V) ─┴─ AMS1117-3.3 (5V→3.3V)
                                    │                        │
                                    ▼                        ▼
                            5V: CH340C、UART传感器、      3.3V: ESP32、INA226、
                            74HCT245 电源                 I2C 传感器、上拉

ESP32-WROOM-32E-N4
   ├─ 12× LEDC PWM ─► 74HCT245 ×2 ─► 12× NCE3080K 栅极
   ├─ I2C ─► INA226 + 2× 板边 XH 接口
   ├─ UART2 ─► 1× 板边 XH 接口 (5V 供电, 3.3V 电平, 兼容 LD2410)
   ├─ 4× 干接点输入 (板上 10k 上拉)
   └─ UART0 ─► CH340C ─► USB Type-C (双三极管自动下载)
```

接法:灯带共阳(V+ 公共),MOSFET 低边斩负极。每条灯带一个 3 位插拔端子:V+ / CW / WW。

## 4. GPIO 分配

| 功能 | GPIO | 备注 |
|---|---|---|
| PWM ×12 | 4, 5, 13, 14, 16, 17, 18, 19, 21, 22, 23, 25 | 全部非 strapping 脚 |
| I2C SDA / SCL | 32 / 33 | INA226 + 板边传感器共用 |
| UART2 TX / RX | 26 / 27 | 板边毫米波接口 |
| 干接点输入 ×4 | 34, 35, 36, 39 | 纯输入脚,板上 10k 外部上拉至 3.3V |
| HCT245 /OE | 15 | 10k 上拉 → 上电输出高阻,灯带不闪;boot 后拉低使能 |
| UART0 TX / RX | 1 / 3 | CH340C 刷机/日志 |
| 状态 LED | 2 | |
| BOOT 按键 | 0 | 自动下载电路亦可控制 |

Strapping 脚 GPIO0/2/12/15 均不承担 PWM/总线职能,刷机与启动无风险。ESP32 LEDC 共 16 通道,12 路同频 19.5kHz,定时器充足。

## 5. 关键电路设计

### 5.1 功率级(×12)
- NCE3080K(30V/80A,Rds(on) ≤10mΩ @ Vgs=5V,TO-252):3A/路导通损耗 <0.1W。
- 栅极:74HCT245 输出 → 100Ω 栅极电阻 → 栅极;10k 栅源下拉。
- 每路输出端子旁 SMBJ28A TVS 对灯带线缆感应瞬态钳位(42V 钳位高于管子 30V Vds,管子有雪崩额定,阻性负载下可接受)。
- 每路 V+ 串 SHV2920P500-30(30V/5A 保持自恢复保险丝),灯带短路不烧板。

### 5.2 输入保护
- 15A ATO 汽车片式保险丝(板载保险丝夹一对,手焊)。
- AO4407A P-MOS 高边防反接;Vgs(max)=±25V,栅极加 12V 稳压管 + 100k 限流钳位。

### 5.3 电平转换
- 74HCT245PW ×2,5V 供电,TTL 输入门限(0.8/2.0V)接受 ESP32 3.3V 电平,输出 5V 驱动栅极。
- 两片 /OE 并联接 GPIO15(10k 上拉):上电高阻 → ESPHome 启动后使能。

### 5.4 功率监测
- INA226(0–36V 共模)+ 2mΩ/2W/2512 合金采样电阻,高边接在防反接之后、总母线上。
- 12A 时:压降 24mV、耗 0.29W(2W 额定余量 >6 倍);满量程 40.96A,12A 用到约 30%。

### 5.5 USB 与电源链
- Type-C(C165948,16P)+ CC 脚 5.1k 下拉;CH340C(免晶振)+ S8050 ×2 自动下载电路。
- XL1509-5.0(40V 耐压,2A)+ SS34 + 33µH/≥2A 电感 → 5V;AMS1117-3.3 → 3.3V。
- 5V 负载:CH340C + HCT245 + UART 传感器(LD2410 约 80mA),<0.5A,余量充足。

### 5.6 传感器与开关接口
- 2× XH2.54-4P:3.3V / GND / SDA / SCL(I2C,仅限板边短线 <1m)。
- 1× XH2.54-4P:5V / GND / TX / RX(UART2,LD2410 直接兼容;成品直通线束注意 TX/RX 交叉)。
- KF128-2.54-5P:4 路干接点 + 公共 GND,ESPHome `binary_sensor`(单击开关/长按调光)。

## 6. 连接器与机械

| 位置 | 选型 | 规格核对 |
|---|---|---|
| 24V 输入 | KF7.62-2P 栅栏式 (C707824) | 24A 额定 vs 12A,2 倍裕量,接 2.5mm² 叉形冷压端子 |
| 输出 ×6 | KF2EDG-3.81 针座 (C441333) + 插头 (C440859) | 7~8A 额定 vs 3A |
| 传感器 ×3 | XH2.54-4P (C37815) | 配成品线束 C385825 |
| 开关输入 | KF128-2.54-5P (C474923) | 信号级 |
| 调试 | 2.54 排针 (C124377) | UART0 + 3.3V + GND |

板子约 12×9cm,四角 M3 安装孔。功率走线:输入到母线、母线到各路端子按 3A/路、12A 主干覆铜加宽并开窗上锡。

## 8. ESPHome 配置要点

- `output`: 12× `ledc`,frequency 19531Hz。
- `light`: 6× `cwww` 平台(cold/warm 各指一路 output),HA 中出现 6 个独立色温灯实体。
- `sensor`: `ina226`(电流/功率/母线电压)。
- `binary_sensor`: 4× `gpio`(34/35/36/39,inverted + 无内部上拉,靠板上外部上拉),配 `on_click`/`on_multi_click` 做开关/调光。
- `switch`/启动脚本: GPIO15 在 boot 完成后拉低使能 HCT245。
- UART2 预留给 `ld2410` 组件(装了传感器再启用)。
- 首刷走 USB-C,其后 OTA。

## 9. 配套建议(范围外)

分散的远端传感器(毫米波/环境)不从本板拉线 —— I2C 超 1m 不可靠、UART 拉长线也麻烦。每个远端点位用 ESP32-C3 核心板(~¥10)+ 传感器组成独立 ESPHome 节点,WiFi 直连 HA。本板的 UART/I2C 接口服务于板子附近的传感器。

## 10. 验证计划

1. 首批贴 2 片。上电前:万用表检查 24V/5V/3.3V 轨无短路。
2. 不接灯带上电:确认 3 轨电压、USB 识别、刷入 ESPHome、WiFi 连接、INA226 读数为 0 附近。
3. 接 1 条灯带小电流验证:PWM 调光/色温曲线、MOSFET 温升、19.5kHz 下无可闻噪声。
4. 满配 6 条(或电子负载模拟 12A):测采样电阻/防反管/走线温升,INA226 读数与钳流表对比。
5. 干接点输入、UART/I2C 接口逐一验证。
6. 无问题 → 补贴 3 片;有改版 → 修版后再决定。

## 11. 风险与开放项

- 汽车保险丝夹未锁定唯一 C 编号,下单时在立创"保险丝座"分类按"中号插片"筛选。
- 33µH/≥2A 功率电感需在下单时从扩展库现货中定型号。
- 价格为抓取快照,下单以系统实价为准(±20%)。
