## 1. 目标与范围

一块定制 PCB,基于 ESP32 + ESPHome,独立控制 **6 条 24V CCT(双色温)灯带**,每条 2 个 PWM 通道(暖白 + 冷白),共 **12 路 PWM**。总线按 **12A @ 24V(288W)** 设计,单通道按 **最大 3A** 设计。接入用户现有 Home Assistant(T630 部署)。

范围内:PCB 原理图/布局、完整 BOM(全部立创商城)、ESPHome 配置。
范围外:远端传感器节点(§9)、外壳。

## 3. 电流预算逻辑(v2 明确)

CCT 灯带标称功率为两通道**合计**。ESPHome `cwww` 平台开 `constant_brightness: true` 后 CW+WW 合计 duty ≤100%,即**每条灯带平均电流 ≤ 单通道满载 3A**。因此:

- 正常模式(constant_brightness on):6 条 × ≤3A = 最坏 18A,仍可能超 12A 总设计 → **固件用 INA226 做总功率软限制**(超限降亮度并上报 HA);
- 若关掉 constant_brightness:理论最坏 36A → 由 15A 主保险丝硬兜底;
- 硬件选型(MOSFET/端子/走线)按每通道 3A 连续、每条灯带正极 3A 连续、母线 12A 连续,均留余量。

## 4. 系统架构

```
24V DC 输入 (LRS-350-24)
   │
   ├─ 15A ATO 片式保险丝 ─ AO4407A P-MOS 防反接 ─┬─ 输入 TVS(SMBJ26A) + 电解 ≥470µF/50V
   │                                             ├─ INA226 + 2mΩ 高边采样 ─► 24V 主母线
   │                                             │      ├─► 6× 输出 V+ (各经 5A 2920 自恢复保险丝 + 本地去耦)
   │                                             │      └─► 12× AOD4184A 低边开关 ◄─ 灯带 CW/WW 负极
   │                                             │           (每路: 100Ω 栅阻 + 10k 下拉 + SS34 续流 + SMBJ26A)
   │                                             └─ 0.75A PTC ─ XL1509-5.0 (24V→5V) ─ AMS1117-3.3
   │                                                              │5V: CH340C/UART传感器/HCT245    │3.3V: ESP32/INA226/温感/I2C
ESP32-WROOM-32E (兼容 32UE 焊盘, BOM 二选一切外置天线)
   ├─ 12× LEDC PWM ─► 74HCT245 ×2 (/OE 上电高阻) ─► 栅极 + 12× 通道指示 LED
   ├─ I2C ─► INA226 + LM75 类温感(MOSFET 区) + XH2.54 + Qwiic(JST-SH) 座
   ├─ UART2 ─► XH2.54 (5V 供电, 兼容 LD2410)
   ├─ 4× 干接点输入 (10k 上拉 + RC 消抖)
   └─ UART0 ─► CH340C(+USBLC6-2 ESD) ─► USB Type-C (CC 5.1k×2, 自动下载)
```

接法:灯带共阳,低边斩负极。每条灯带一个 3 位插拔端子:V+ / CW / WW。

## 6. 关键电路设计

### 6.1 功率级(×12)
- **AOD4184A**(40V/50A,TO-252,Rds(on) ≤9.5mΩ @ Vgs=4.5V 手册保证):3A 导通损耗 <0.03W。40V 耐压对 24V 母线余量充足(v1 的 30V 管余量不足,已按 QuinLED 实践修正)。
- 栅极:100Ω 串阻(有意放缓边沿抗 EMI,QuinLED 思路)+ 10k 栅源下拉(上电防浮空)。
- **每路 SS34 续流二极管**(漏极→V+,吸收长灯带线感抗关断尖峰)+ SMBJ26A TVS(钳位 42.1V < 40V 管的雪崩区,双保险)。
- 每路 V+ 串 SHV2920P500-30 自恢复保险丝;输出端子旁本地去耦(电解 + MLCC)。
- 每路一颗指示 LED 接 HCT245 输出侧(不碰功率级),调试直观。
- 12 路 CW/WW 成对相位错开(LEDC 支持),电源纹波电流减半。

### 6.2 输入保护(三级保险结构)
- 主路:15A ATO 汽车片式保险丝(板载保险丝夹,手焊)→ **AO4407A ×2 并联**防反接(单颗 12A 下损耗 ~1.4W SOIC-8 过热,并联后每颗 0.36W;栅极 12V 稳压管 + 100k 钳位)。
- 输入 TVS SMBJ26A + 电解 ≥470µF/50V(QuinLED "重去耦"实践)。
- 逻辑支路:独立 0.75A PTC 自恢复保险(与 LED 主路分开,逻辑电源故障不牵连主路)。

### 6.3 电平转换
- 74HCT245PW ×2,5V 供电,TTL 门限接受 3.3V 输入;/OE 并联接 GPIO15。
- **/OE 上拉 10k 必须接 5V 轨**(不能接 3.3V 轨):5V 先于 3.3V 爬升的窗口内,若上拉接 3.3V 则 /OE 为低、输入悬空,12 路可能上电闪光(H801 病)。上拉接 5V 后该窗口 /OE 恒高。GPIO15 固件配置为**开漏模式**(避免 3.3V 推挽对 5V 上拉倒灌)。
- AOD4184A Qg≈14nC@4.5V,19.5kHz 下平均栅流 <0.3mA/路,HCT245 直驱无压力。

### 6.4 功率监测与温度
- INA226 + 2mΩ/2W/2512,高边接于防反接之后总母线;12A 时压降 24mV、耗 0.29W,满量程 40.96A。
- **板载 I2C 温感(LM75B 类)置于 MOSFET 区**,固件做过热降额(QuinLED 实践)。

### 6.5 USB 与电源链
- Type-C(16P)+ CC1/CC2 各 5.1k 下拉(开源板高频翻车点,重点检查项)+ **USBLC6-2 ESD 阵列**;CH340C + S8050×2 自动下载。
- **USB VBUS 经肖特基二极管 OR 进 5V 轨**(与 XL1509 输出隔离):不接 24V 也能 USB 刷机/调试逻辑部分;24V 在场时 XL1509 电压更高自动接管。
- XL1509-5.0(40V 耐压 150kHz)→ 5V:布局按 datasheet 最小环路,电感 33µH 饱和电流 ≥2A;AMS1117 → 3.3V(WiFi 突发预算 ≥600mA;峰值损耗 ~0.85W,布局留覆铜,样板实测温升)。

### 6.6 传感器与开关接口
- **接口物理防呆**:I2C **只用 Qwiic(JST-SH 1.0mm 4P,3.3V)**;XH2.54-4P **只做 UART 口(5V)** —— 两种接口互不可插,杜绝"3.3V 传感器插上 5V 口烧毁"的误插风险,配丝印电压标注。I2C 仅限板边短线 <1m。
- UART2:1× XH2.54-4P(5V/GND/TX/RX,LD2410 直插;直通线束注意 TX/RX 交叉)。
- 干接点:KF128-2.54-5P,每路 10k 上拉 + **1k 串联限流(长线 ESD/干扰注入防护)** + RC 消抖(100nF);GPIO36/39 errata(WiFi 省电模式偶发毛刺)由固件 `delayed_on: 30ms` 兜底。

### 6.7 WiFi 天线
- 布 WROOM-32E/32UE 兼容焊盘,BOM 二选一:塑料盒用 32E 板载天线,金属箱换 32UE + IPEX 外置天线(社区实测金属盒内差 20dB)。天线区按乐鑫要求禁铜,模组置板边、远离功率区。

## 7. 布局要点

- 2oz 铜;24V/GND 双面大面积覆铜,MOSFET 漏极焊盘过孔阵列到背面覆铜散热(QuinLED "铜面即散热片")。
- 主电流脊椎(输入→保险→防反→采样→分配点,12A 段)双面 15~20mm 覆铜 + 过孔缝合 + 开窗堆锡(IPC-2221:2oz/10mm 即满足 12A@ΔT10℃,双面再对折);过分配点后每支路 ≤3A。**脊椎段预留 2× M3 孔位**,实测温升超预期时可外拧铜排/铜线旁路(零成本改版保险)。
- 每路 2920 自恢复保险丝**远离 MOSFET 发热区布置**(PPTC 保持电流高温降额,60℃ 时降至约 4A)。
- 功率区与 ESP32/模拟区分区,INA226 采样走线开尔文连接。
- 丝印直接印接线图:每端子标 "CH1 V+/CW/WW"、"24V IN MAX 12A"、输入极性、接口电压(Qwiic 3.3V / XH-UART 5V);测试点用裸铜焊盘阵列(见 §8.2)。
- **⚠️ 所有元件(贴片 + 插件)必须布置在顶层单面** —— 嘉立创经济型 SMT 仅支持单面焊接,这是实现"用户零焊接"的前提(§8.5)。背面仅用于覆铜散热与走线。

**尺寸估算:约 100 × 115mm**(略小于 A6 明信片),四角 M3 安装孔。

尺寸由**输出端子边长**决定,而非元件面积:6 个 3.81mm 三位端子每个占约 13mm,连排 78mm,加边距后宽度需 ≥90mm。深度按功能分层:

| 分区 | 深度 | 内容 |
|---|---|---|
| 输出区 | ~42mm | 6 条通道:端子 → 自恢复保险丝 → 2× MOSFET + 续流管 + TVS |
| 驱动区 | ~18mm | 2× 74HCT245 + 栅阻 + 12 颗通道指示灯 |
| 功率脊椎 | ~25mm | 输入端子、保险丝座、防反管 ×2、采样电阻、INA226、大电解 |
| 控制区 | ~30mm | ESP32(含天线净空)、CH340C、Type-C、按键、Qwiic/XH、开关端子 |

12 只 MOSFET 几乎不占面积(3A 下每只损耗仅 0.086W,无需散热铜面,TO-252 可紧密排布)。立体包络约 **120 × 115 × 25mm**(端子插头插上后向外再伸约 20mm,需留接线手指空间)。

尺寸超出嘉立创 100×100mm 最优惠档位,**不为此压缩布局** —— 多出的打样费仅数十元,而宽松布局换来更好的散热、走线与接线体验(墙面明装、需经常插拔)。

## 9. ESPHome 配置要点

- 12× `ledc` @19531Hz(12-bit),CW/WW 成对 `phase_angle` 错开 180°(YAML 阶段验证当前 ESPHome 版本支持)。
- 6× `cwww`,**`constant_brightness: true`**(防灯带双通道同满载超额定);`restore_mode` 默认**恢复断电前状态**(避免半夜来电全屋亮灯)。
- GPIO15(HCT245 /OE)配开漏模式;`on_boot` 中**在 light 组件状态恢复之后**才拉低使能,顺序不可反。
- 墙壁开关→灯的联动逻辑写成**板内本地自动化**(不经 HA 回环):WiFi/HA 挂掉时物理开关仍可控灯。
- INA226 总功率软限制:超 288W 触发全局降亮度 + HA 告警;`wifi_signal` 传感器随配(诊断金属盒信号)。
- LM75 温感 → 过热(如 >80℃)自动降功率。
- 低亮度调光:`gamma_correct` 默认 2.8,台阶感明显时降 2.2;output 设 `min_power` + `zero_means_zero`;规格诚实标注 ~1000:1 调光比(最低几级 duty 受开关沿限制不保真)。
- PWM 频率预设注释:日常 9765Hz/13bit、拍视频 39062Hz/11bit(QuinLED 档位),默认 19531Hz。
- 4× `binary_sensor` 干接点:单击开关、长按调光。
- GPIO15 boot 脚本拉低使能 HCT245;UART2 预留 `ld2410`。
- ESPHome YAML 随硬件工程一起入库发布(开源社区实践)。

## 9a. 安装与长期运行(家用安全条款)

**⚠️ AC 侧安全(最重要):LRS-350-24 的 220V 输入端子是暴露螺钉。** 墙面安装必须:① 加装明纬原厂端子护盖,或电源+板子整体入通风箱体;② AC 进线经带保险丝的插座或空开;③ **地线必须接**(金属壳电源接地要求)。24V 侧为 SELV 安全电压,可裸露;AC 侧必须物理隔离。

- **接线工艺**:所有螺钉端子内的多股线**必须压管型冷压端子(线鼻子),严禁镀锡后直接压螺钉**(锡冷流→松动→发热,火险第一路径)。安装满一个月复拧一次端子,此后每年一次。
- **外壳**:洞洞板裸装短期可行,长期建议带通风孔 ABS 盒(防尘/防虫桥接/防误触);裸装期间板子竖装少积灰。
- **可闻噪声**:19.5kHz 成人听不到,小孩/宠物可能听到(声源多为灯带 FPC/电感磁致伸缩);如被投诉,固件切 39kHz 预设。
- **耗材认知**:电源内电解电容寿命 5~8 年,LRS-350 视为定期更换件;板上 105℃ 电解低温升下寿命 10 年+。
- **健康监测**:HA 里对 INA226 功率做长期统计 —— 同亮度下功率逐年漂移 = 灯带/电源老化早期信号;某路灯灭仍有电流 = 接线异常。
- **年检清单**(3 分钟):复拧端子、看 INA226 基线、吹灰。

## 11. 验证计划

1. 首批贴 2 片;上电前万用表查 24V/5V/3.3V 轨短路。

## 12a. 扩展路径:超过 6 条灯带怎么办

**结论:加板,不要试图在单板上加通道。**

8 条 CCT(16 路 PWM)在单块经典 ESP32 上做不成。LEDC 通道数勉强够(16 个,零余量),但**引脚卡死**:WROOM-32E 上"可输出且非启动敏感"的引脚恰好只有 16 个(GPIO 4/5/13/14/16/17/18/19/21/22/23/25/26/27/32/33),16 路 PWM 会全部占满,I2C 与 UART 传感器口一个不剩。剩下的 strapping 脚不能承担 I2C —— I2C 必须挂上拉电阻,而 GPIO12 上电被拉高会令 ESP32 按 1.8V flash 电压启动(**板子无法开机**),GPIO2 被拉高则破坏自动下载。因此单板 8 条的代价是砍掉 INA226、温感与全部传感器接口,即本设计的全部差异化。

电源侧问题更大:8 条 × 3A = **24A / 576W**,需换 LRS-600-24,且板上 12A 脊椎、15A 主保险、输入端子全部要重新设计,并把 576W 集中于单点。

**正解**:6 条以上按 4+4 或 6+2 分为两块板,架构原样复用、功率分散、可就近安装(省 24V 长线压降)、单板故障只影响一半灯光;边际成本仅一块板(~¥130~167),而备板本就在计划内。HA 中呈现为两个 ESPHome 设备,使用体验无差别。
