# 6 路 CCT 灯带 ESPHome 驱动板 — 设计文档 v7

日期:2026-08-02(v7 = v6 + 保护架构重构 + GPIO15 电路修正 + 电源回归 LRS + 灯带参数确定)
状态:待用户批准,可进入原理图

**v7 变更摘要**
1. **支路保护:PPTC → 4A 慢断可更换保险丝**(最高优先级,PPTC 在限流电源下无法可靠切断短路)
2. **防反接 P-MOS 兼作 MCU 可控总断路开关**(增量 <¥1,应对 MOS 短路导致的通道常亮)
3. **⚠️ 修正 v3 的一个真 bug:GPIO15 不可直接挂 5V 上拉**,改用小 N-MOS 隔离(见 §6.3)
4. **电源回归明纬 LRS-350-24**(¥117.8,立创现货)+ TBC-09 端子盖 + 通风箱体
5. **灯带参数确定**:单条最大 5m × 14W/m = 70W = 2.92A
6. **线材加粗**:灯带线 0.5mm² → **0.75~1.0mm²**(5m/2.92A 下压降 4.3% → 2.2%)
7. **不做 3 路精简版**(成本分析见 §12b)
8. 首版保留全部保护器件焊盘,样机实测后再决定 DNP(见 §12c)

**未决**:`restore_mode` 取 `ALWAYS_OFF`(来电一律不亮)还是 `RESTORE_DEFAULT_OFF`(恢复断电前状态)—— 使用偏好,不阻塞设计。

## 1. 目标与范围

一块定制 PCB,基于 ESP32 + ESPHome,独立控制 **6 条 24V CCT(双色温)灯带**,每条 2 个 PWM 通道(暖白 + 冷白),共 **12 路 PWM**。主电流路径按 **15A 连续承载**设计,正常运行预算限制为 **≤12A @ 24V(288W)**,单通道按 **最大 3A** 设计。接入用户现有 Home Assistant(T630 部署)。

范围内:PCB 原理图/布局、板载电子 BOM(立创商城)与板外采购表、ESPHome 配置。
范围外:远端传感器节点(独立立项,含 433MHz 收发)。

## 3. 电流预算逻辑(v2 明确)

CCT 灯带标称功率为两通道**合计**。ESPHome `cwww` 平台开 `constant_brightness: true` 后 CW+WW 合计 duty ≤100%,即**每条灯带平均电流 ≤ 单通道满载 3A**。因此:

- 正常模式(`constant_brightness: true`):6 条 × ≤3A = 理论最坏 18A,因此必须在 ESPHome 中按实测灯带电流设置每条最大输出比例,使总配置上限 **≤12A**;INA237 超限后降亮度并上报 HA,仅属于运行管理。
- **INA237/ESPHome 软限流不是短路或过流安全保护**。硬保护由电源限流、15A 主保险丝和各支路 **4A 慢断可更换保险丝**共同承担。
- 禁止在本硬件上关闭 `constant_brightness` 后允许 12 路同时满载;理论 36A 已超出输入端子、保险丝和母线能力。
- MOSFET/端子/支路按每通道 3A 连续设计;主输入路径和铜箔按 15A 连续设计;正常运行由配置限制在 12A 内。若实测需求超过 12A,采用两块板/两台电源分区,不提高单板限值。

## 4. 系统架构

```
24V DC 输入 (明纬 LRS-350-24, 350W/14.6A, 限流约 15~19A)
   │
   ├─ 15A ATO 片式保险丝 ─ SUD50P06-15 ×2 P-MOS 防反接 ─┬─ 输入 TVS(SMBJ26A) + 电解 ≥470µF/50V
   │                                             ├─ INA237 + 2mΩ 高边采样 ─► 24V 主母线
   │                                             │      ├─► 6× 输出 V+ (各经 4A 慢断可更换保险丝 + 本地去耦)
   │                                             │      └─► 12× NTD5865NLT4G 低边开关 ◄─ 灯带 CW/WW 负极
   │                                             │           (每路: 100Ω 栅阻 + 10k 下拉 + SS36 续流 + SMBJ26A)
   │                                             └─ 0.75A PTC ─ TX4144 (24V→5.25V) ─ SS34 ─┐
USB VBUS ─ SS34 ───────────────────────────────────────────────────────────────────────────┤─ 5V_SYS ─ AMS1117-3.3
                                                                                           │5V: UART传感器/HCT245
                                                                                           │3.3V: ESP32/CH340C/INA237/I2C
ESP32-WROOM-32E (兼容 32UE 焊盘, BOM 二选一切外置天线)
   ├─ 12× LEDC PWM ─► 74HCT245 ×2 (/OE 经 NPN 隔离、上电高阻) ─► 栅极 + 12× 通道指示 LED
   ├─ I2C ─► INA237 + Qwiic(JST-SH) 座
   ├─ UART2 ─► XH2.54 (5V 供电, 兼容 LD2410)
   ├─ 4× 干接点输入 (10k 上拉 + RC 消抖)
   └─ UART0 ─► CH340C ─► USB Type-C (CC 5.1k×2, 自动下载)
```

接法:灯带共阳,低边斩负极。每条灯带一个 3 位插拔端子:V+ / CW / WW。

| UART0 | 1 / 3 | CH340C |
| 状态 LED | 2 | |
| BOOT 键 | 0 | |

**⚠️ strapping 脚使用说明(v7 修正 —— 早期版本误称"全非 strapping")**

ESP32 的 strapping 脚为 **GPIO0、2、5、12、15**,本设计占用了其中三个。引脚已全部用满(26 个可用脚全部分配),无非 strapping 脚可替换,因此逐一论证安全性:

| 脚 | 用途 | 启动时的外部电气状态 | 判定 |
|---|---|---|---|
| **GPIO5** | CH1_WW PWM | 仅接 74HCT245 的 CMOS 输入(高阻),**不构成任何外部上拉/下拉** → 保持内部上拉的默认态 | ✅ 安全 |
| **GPIO2** | 状态 LED | LED 串 1kΩ 到地 = 弱下拉,而低电平**正是进入下载模式所要求的状态** | ✅ 安全 |
| **GPIO15** | /OE 控制 | 经 R14(10k)+ R15(100k)到地 = 弱下拉 → 读低 → 仅关闭 ROM 引导日志 | ✅ 安全 |
| **GPIO0** | BOOT 键 | 10k 上拉到 3V3,按键按下才接地 | ✅ 标准接法 |
| **GPIO12** | **不接** | 全程悬空 | ✅ 必须保持悬空 |

固件中对 GPIO5/2/15 显式声明 `ignore_strapping_warning: true` 并附注理由,**不是压制警告,而是把论证固化下来** —— 后续若改动这三个脚的外围电路,必须重新走一遍上表的判定。

## 6. 关键电路设计

### 6.1 功率级(×12)
- **NTD5865NLT4G(UMW)**(60V/46A,TO-252,Rds(on) ≤19mΩ @ Vgs=4.5V):按 3A 连续计算,25℃导通损耗上限约 **0.17W/只**;高温导阻上升后按 0.3W/只预留散热。相对 40V MOS,可与 SMBJ26A 的 42.1V 最大钳位电压形成有效耐压余量。
- 栅极:100Ω 串阻(有意放缓边沿抗 EMI,QuinLED 思路)+ 10k 栅源下拉(上电防浮空)。
- **每路 SS36 续流二极管**(漏极→V+,吸收长灯带线感抗关断尖峰)+ SMBJ26A TVS(最大钳位约 42.1V,低于 60V MOS 耐压)。二极管和 TVS 的极性、回路位置必须在原理图中明确;是否能删减其中之一仅由长线实测波形决定。
- **每路 V+ 串可更换慢断保险丝(v7 重构,原 PPTC 方案作废)**:
  - **作废理由**:PPTC 保持 5A、跳闸需约 2 倍(10A),而开关电源故障时进入恒流限流(LRS-350 约 15~19A,HLG-320H 仅 13.34A),倍数不足会导致数秒至数十秒才动作,甚至始终不跳 —— **无法可靠隔离短路**。
  - **新方案**:4A 慢断(T 型)、额定电压 ≥32V DC 的可更换保险丝。LRS-350 故障电流 15~19A = **3.8~4.8 倍 → 0.05~0.5 秒切断**。
  - **按实际灯带功率选规格**(可更换的额外好处):5m/2.92A → 4A;3m/1.75A → 2.5A;2m/1.17A → 2A。短灯带用小规格,熔断倍数更高、动作更快。板子出厂按最坏情况配 4A。
  - 保险丝座选型待定(需兼顾板面积与可更换性),备选:Nano2 贴片座、5×20mm 管座、mini 片式座。
- 输出端子旁本地去耦(电解 + MLCC)。
- 每路一颗指示 LED 接 HCT245 输出侧(不碰功率级),调试直观。
- 12 路 CW/WW 成对相位错开(LEDC 支持),用于降低同相开关造成的峰值纹波;改善量必须以总线电流波形验证,不预先承诺“减半”。

### 6.2 输入保护(三级保险结构)
- 主路:15A ATO 汽车片式保险丝(板载保险丝夹,手焊)→ **SUD50P06-15(UMW) ×2 并联**防反接(-60V,TO-252,Rds(on) ≤15mΩ @ -10V)。12A 时两只并联的总导通损耗上限约 1.08W,即约 0.54W/只(不含高温增量);栅极 12V 稳压管 + 100k 钳位。
- 输入 TVS SMBJ26A + 电解 ≥470µF/50V。TVS 最大钳位约 42.1V,低于防反管、输出 MOS 和 buck 的 60V 耐压。
- 逻辑支路:独立 0.75A PTC 自恢复保险(与 LED 主路分开,逻辑电源故障不牵连主路)。
- 主 ATO 保险丝与各支路慢断保险丝均须按具体料号的 **DC 额定电压**、时间-电流曲线和环境温度降额校核;"15A/4A" 标称值不代表瞬时精确动作点。支路保险丝 DC 额定 **≥32V**,以覆盖 SMBJ26A 的 42.1V 钳位瞬态。
- **原 PPTC 方案(SHV2920P500-30)已于 v7 作废**,两个独立理由:
  1. **动作倍数不足**:保持 5A、跳闸约需 2 倍(10A),而电源故障时进入恒流限流(LRS-350 约 15~19A),倍数不够会导致数秒至数十秒才动作甚至不跳,无法可靠隔离短路;
  2. **耐压不足**:该型号最大工作电压仅 30V,低于 SMBJ26A 的 42.1V 钳位瞬态。
  替换为 4A 慢断、DC 额定 ≥32V 的**可更换保险丝**(见 §6.1)。选座原则:兼顾板面积与可更换性,首选 Nano2/6125 贴片保险丝座(约 6.1×2.5mm),备选 5×20mm 管座(体积大)与 mini 片式座(单价高)。具体料号与价格下单前核实。

### 6.3 电平转换
- 74HCT245PW ×2,5V 供电,TTL 门限接受 3.3V 输入;两片 `/OE` 并联,但**不得直接连接 ESP32 GPIO**。
- `/OE` 用 10k 上拉到 5V_SYS,再由一颗 MMBT3904(NPN)集电极开路下拉:集电极接 `/OE`,发射极接 GND,GPIO15 经 10k 驱动基极,基极另加 100k 下拉。上电/复位时 NPN 默认关闭、`/OE` 保持高电平;boot 完成后 GPIO15 输出高电平使 NPN 导通,才启用 12 路。这样 ESP32 引脚不会承受 5V。
- NTD5865 的 Qg 高于原 40V MOS,不能仅凭平均栅流判断 HCT245“无压力”。样板必须示波器测量 HCT 输出和 MOS 栅极上升/下降时间,据此计算开关损耗;若边沿过慢或 HCT 压降过大,改用专用多路栅极驱动器或降低 PWM 频率。

### 6.4 功率监测与温度
- **INA237 + 2mΩ/2W/2512**,高边接于防反接之后总母线;12A 时压降 24mV、耗 0.29W。选 ±40.96mV ADC 档时满量程 20.48A,覆盖 15A 验证且分辨率更高。INA237 的共模范围为 -0.3~85V,可承受本设计 42.1V 钳位瞬态;原 INA226 仅 36V 工作范围,不再采用。
- **板载温感仍不装配**,但不能用 INA237 电流/功率或芯片结温读数代替接插件和焊点温度监测:接触电阻升高时总电流可能基本不变。PCB 保留靠近输入端子/防反管的 DNP 温感焊盘或通过 Qwiic 临时接温感器;首板以热像仪/热电偶完成 12A 连续和 15A 短时验证后再决定是否永久省略。

### 6.5 USB 与电源链
- Type-C(16P)+ CC1/CC2 各 5.1k 下拉(开源板高频翻车点,重点检查项);CH340C + S8050×2 自动下载。**USB ESD 阵列已砍除(v6)** —— 该口仅首刷时使用一次,此后全走 OTA,保留 ESD 芯片性价比低。
- **USB VBUS 与 buck 输出必须各自经过一颗 SS34 后再汇入 5V_SYS**,形成真正的双向隔离 diode-OR;禁止只隔离 USB 而让 USB 反灌 buck 输出。TX4144 初始设为约 5.25V,样板按 SS34 实测压降微调,使 5V_SYS 在 4.8~5.1V 且两路互不反灌;USB 单独供电时仍能刷机/调试逻辑部分。
- **CH340C 用 3.3V 供电**,按数据手册连接 V3/VCC,避免 5V 供电时 TXD 高电平直接进入 ESP32。HCT245 和 5V UART 传感器仍使用 5V_SYS。
- TX4144(6~60V、1.5A、可调输出)→ 5.25V:按 datasheet 重新选择反馈电阻、电感和肖特基二极管,布局保持最小开关环路;AMS1117 → 3.3V(WiFi 突发预算 ≥600mA;峰值损耗 ~0.85W,布局留覆铜,样板实测温升)。

### 6.6 传感器与开关接口
- **接口物理防呆**:I2C **只用 Qwiic(JST-SH 1.0mm 4P,3.3V)**;XH2.54-4P **只做 UART 口(5V)** —— 两种接口互不可插,杜绝"3.3V 传感器插上 5V 口烧毁"的误插风险,配丝印电压标注。I2C 仅限板边短线 <1m。
- UART2:1× XH2.54-4P(5V/GND/TX/RX,LD2410 直插;直通线束注意 TX/RX 交叉)。
- 干接点:KF128-2.54-5P,每路 10k 上拉 + **1k 串联限流(长线 ESD/干扰注入防护)** + RC 消抖(100nF);GPIO36/39 errata(WiFi 省电模式偶发毛刺)由固件 `delayed_on: 30ms` 兜底。

### 6.7 WiFi 天线
- 布 WROOM-32E/32UE 兼容焊盘,BOM 二选一:塑料盒用 32E 板载天线,金属箱换 32UE + IPEX 外置天线(社区实测金属盒内差 20dB)。天线区按乐鑫要求禁铜,模组置板边、远离功率区。

## 7. 布局要点

- **1oz 铜(v6 确认)**;24V/GND 双面大面积覆铜,MOSFET 漏极焊盘过孔阵列到背面覆铜散热(QuinLED "铜面即散热片")。
- **主电流脊椎按 15A 连续承载设计**:双面 ≥20mm 覆铜 + 过孔缝合 + 明确定义的阻焊开窗/钢网加锡区域;不能假定沉金板会自动“堆锡”,也不预先把加锡效果写成固定百分比。以 IPC-2152/板厂能力完成初算,最终由 12A 连续、15A 短时热像测试验收。过分配点后每支路 ≤3A,1oz 下建议 ≥3mm。**脊椎段预留 2× M3 孔位**,必要时外加铜排/铜线旁路。
- 每路保险丝座**远离 MOSFET 发热区布置**(保险丝额定电流随环境温度降额,且需留出更换保险丝的操作空间与镊子夹取余量)。
- 功率区与 ESP32/模拟区分区,INA237 采样走线开尔文连接。
- 丝印直接印接线图:每端子标 "CH1 V+/CW/WW"、"24V IN MAX 12A"、输入极性、接口电压(Qwiic 3.3V / XH-UART 5V);测试点用裸铜焊盘阵列(见 §8.2)。
- **⚠️ 所有元件(贴片 + 插件)必须布置在顶层单面** —— 嘉立创经济型 SMT 仅支持单面焊接,这是实现"用户零焊接"的前提(§8.5)。背面仅用于覆铜散热与走线。

**尺寸定稿:110 × 145mm**(v15,用户要求电源与灯带全部从上边接线:24V 输入 J1 居上边最左,CH1–CH6 依次向右;输入保护链移至左列,主干不折返)。四角 M3 安装孔。亚克力三明治 120×155mm ×2(372cm²,仍在免费打样 500cm² 限额内)。

#### 电源方案决策(v7 复核)

**首选 HLG-320H-24,放弃 LRS-350 + 箱体方案。** 依据(明纬官方规格书 2026-02-04 版):

| | LRS-350-24 | **HLG-320H-24** |
|---|---|---|
| AC 端子 | 9 颗裸螺钉全暴露 | **预置三芯橡套软线(300mm),无任何螺钉** |
| 防护等级 | 无 | IP65/IP67 |
| 效率 / 自耗散 | 88% / ~40W | **94% / ~20W** |
| 冷却 | **内置风扇**(RTH3 ≥50℃ 开,≤40℃ 停)→ 有噪音 | **无风扇,自然对流** |
| 是否需要箱体 | **必须**(且必须开对流孔) | **不需要,自身即成品外壳** |
| 保固 / PFC | 2 年 / 无 | 7 年 / 有(PF≥0.95) |

关键论证:HLG 自耗散仅为 LRS 的一半且敞开散热,**整套方案的热安全性反而优于"LRS 关在箱子里"**。同时它把"箱体难看"这一问题从根上取消。

**恒压可行性**:HLG 为 CV+CC 混合模式,输出电流 <13.34A 时按恒压 24V 工作(容差 ±1.0%),可直接驱动灯带。选型:无后缀(固定 24V)或 A 型(21~26V 可调,可补偿长线压降,但 A 型为 IP65);**不可选 C 型**(无 IP 认证)。

**⚠️ 降额与安装纪律(硬约束)**

官方寿命曲线:**Tc ≤70℃ → 100,000h;Tc = 80℃ → 约 55,000h;Tc = 90℃ → 仅约 25,000h**(Tcase 上限 90℃,规格书注 9:tc ≤75℃ 时 >62,000h)。满载 320W 时自耗散约 19W,自然对流下壳温典型落在 **60~75℃** —— 在规格内,但摸上去烫手且明显折寿。

因此:
1. **按 60~70% 负载选型** —— 320W 机器挂 ≤220W 灯带,壳温可压到 50~60℃、寿命拉满。**若实际灯带总功率 >250W,应用两台分区供电,而非一台跑满**(与 §12a"加板不加通道"的分区思路一致)。
2. **必须装在人手够不到的位置**(灯槽内/柜顶/墙面高处);金属表面 >65℃ 持续接触即有低温烫伤风险。
3. **散热鳍片朝外、长轴竖直、离墙 ≥15mm**(4 个 φ4.5 安装孔);**贴墙平放最糟**,等于堵死一半散热面。
4. **黄绿地线必须可靠接 PE** —— HLG/ELG/台达均为 Class I 金属外壳设备,不接地外壳会带感应电。
5. AC 软线接头必须端接在接线盒内,不得用绝缘胶布缠绕。

**⚠️ 采购防坑**:1688 上标价"¥100 起"的 HLG-320H-24 几乎可断定为翻新/仿冒(正品海外授权价 US$100+)。此为直接接 220V 的设备,务必走京东明纬专卖店或明纬授权经销商。

**本项目当前筛选结论**:能取得完整规格书、认证和质保信息的 24V 灌封 CV+CC 候选集中在 300~320W 档;不能据此断言所有 IP67 电源都存在同一功率上限。对电商标称“24V 400W IP67”但无完整 datasheet、认证主体和温升/降额曲线的产品一律排除。需要更大功率时采用**多台分区供电**。

**已排除的选项**:LPV 系列上限 150W(无 LPV-320);明纬导轨系列 24V 无 350W 档(仅 75/120/240/480W),NDR-240 不足、NDR-480 超配且仍需箱体;正泰 PZ30 及各类弱电箱方案随 LRS 一并放弃。ELG 系列存在 ELG-300-24A,不得再写成“最高 240W”;其在低输入电压地区会降额,本项目按 220V AC 使用仍须核对具体规格书。

**待确认**:HLG-320H-24 的国内确切售价与立创是否在售(立创确认有同系列 60H-24A/120H-24A/320H-42AB/320H-48A,但 320H-24 未取到页面)。若价格远超 ¥500,退路为 LRS-350-24 + **TBC-09 端子盖**(明纬官方件,官网产品页 URL 明确标注适配 `lrs-200-350`,约 $0.32,立创无售但嘉立创 FA 商城有 TBC 系列)+ 带对流孔的白色弱电箱(德力西 400×300×120 级,¥100~145)。注意 TBC-09 仅为 88.7×10×3.8mm 薄盖条,**不提供 IP 防护、导线进入侧仍敞开**,不能单独替代外壳。

**⚠️ 三条必须遵守的安装约束**

1. **LRS-350-24 的风扇在顶盖上**(顶面一端的圆形风扇网),顶面与侧面都有百叶孔。因此电源在箱内必须**顶面朝上、上方留 ≥30mm 净空**,绝不能平贴箱底或被压住 —— 否则风扇等于没有。

## 9. ESPHome 配置要点

- 12× `ledc` @19531Hz(12-bit),CW/WW 成对 `phase_angle` 错开 180°(YAML 阶段验证当前 ESPHome 版本支持)。
- 6× `cwww`,**`constant_brightness: true`**(防灯带双通道同满载超额定);ESPHome 的 `restore_mode` 默认是 `ALWAYS_OFF`,本设计显式设置为 **`RESTORE_DEFAULT_OFF`**(允许恢复已保存状态,但无有效状态时默认关灯),不得依赖默认值。
- GPIO15 驱动 `/OE` 隔离 NPN:GPIO15 低/高阻 = 输出禁用,GPIO15 高 = 输出启用;`on_boot` 中**在 light 组件状态恢复且 12 路 PWM 已写入安全值之后**才输出高电平,顺序不可反。
- 墙壁开关→灯的联动逻辑写成**板内本地自动化**(不经 HA 回环):WiFi/HA 挂掉时物理开关仍可控灯。
- INA237 用 ESPHome `ina2xx_i2c`、`model: INA237`、`shunt_resistance: 0.002 ohm`、`max_current: 20 A`、`adc_range: 1`;建议 264W(11A)预警,288W(12A)触发全局降亮度 + HA 告警。不得在文档、YAML 或 UI 中称其为保险/短路保护;`update_interval`、ADC 转换时间与平均次数须按控制响应目标显式设置,不能沿用 60s 默认慢周期。
- 低亮度调光:`gamma_correct` 默认 2.8,台阶感明显时降 2.2;output 设 `min_power` + `zero_means_zero`;规格诚实标注 ~1000:1 调光比(最低几级 duty 受开关沿限制不保真)。
- PWM 频率预设注释:日常 9765Hz/13bit、拍视频 39062Hz/11bit(QuinLED 档位),默认 19531Hz。
- 4× `binary_sensor` 干接点:单击开关、长按调光。
- GPIO15 boot 脚本拉低使能 HCT245;UART2 预留 `ld2410`。
- ESPHome YAML 随硬件工程一起入库发布(开源社区实践)。

## 9a. 安装与长期运行(家用安全条款)

**⚠️ AC 侧安全(最重要):本项目已选定 LRS-350-24,其 9 个 220V 端子为裸露螺钉,以下三项为强制要求:**
1. **加装明纬原厂 TBC-09 端子盖**(官方件,适配 LRS-200/350,88.7×10×3.8mm)。注意它只是挡住螺钉头的薄盖条,**不提供 IP 防护、导线进入侧仍敞开**,不能单独作为安全措施;
2. **整机装入通风箱体** —— LRS-350-24 内置风扇(≥50℃ 启动)且满载自耗散约 48W,**密闭箱不可行**(风扇在密闭腔内只是内循环,热出不去),必须有进/出风路;
3. **上游有合适的保险/空开,黄绿地线可靠接 PE**(LRS 金属壳为 Class I 设备)。

24V 属 SELV 不等于大电流侧可任意裸露;驱动板必须防金属异物掉落和端子误触。

**选型取舍记录**:曾评估灌封 IP67 电源(HLG-320H-24 等),其优势是 AC 侧预置线缆无裸露端子、无风扇、自耗散仅 20W、不需要箱体;放弃原因是价格约 ¥400(LRS 为 ¥117.8)、立创无收录需走京东/授权经销商、且 1688 低价货源有翻新仿冒风险。改用 LRS 后,上述三项强制要求即是用工程措施补回被放弃的安全性。

- **接线工艺**:所有螺钉端子内的多股线**必须压管型冷压端子(线鼻子),严禁镀锡后直接压螺钉**(锡冷流→松动→发热,火险第一路径)。安装满一个月复拧一次端子,此后每年一次。
- **外壳**:亚克力三明治若四周开放,只能用于台架调试。长期安装采用带通风孔的阻燃 ABS/PC 外壳或增加完整侧壁/防落物罩,同时保留自然对流空间。
- **可闻噪声**:19.5kHz 成人听不到,小孩/宠物可能听到(声源多为灯带 FPC/电感磁致伸缩);如被投诉,固件切 39kHz 预设。
- **寿命认知**:不再用“电源 5~8 年、板上电解 10 年+”这类固定年限代替计算。电解寿命取决于具体料号、纹波电流与热点温度;电源按厂家寿命曲线和质保执行,板上电解在样板测得壳温后按 datasheet 寿命/温度规则估算,并以年度外观、温升和纹波检查决定更换。
- **健康监测**:HA 里对 INA237 功率做长期统计 —— 同亮度下功率逐年漂移 = 灯带/电源老化早期信号;某路灯灭仍有电流 = 接线异常。
- **年检清单**(3 分钟):复拧端子、看 INA237 基线、吹灰。

## 11. 验证计划

1. 5 片一次贴完,先只给其中 2 片上电;上电前万用表查 24V/5V_SYS/3.3V 轨短路。
2. 仅 USB 供电(不接 24V):验证 VBUS diode-OR 供电下能识别、能刷机,并确认 USB 不向 TX4144 输出端反灌。再 24V 空载上电:三轨电压 → USB 识别(重点验 CC 下拉:用 C-to-C 线测)→ 刷 ESPHome → WiFi → INA237 读数;同时确认 24V 供电不会向主机 USB VBUS 反灌。
2a. 上电时序:示波器/目视确认 5V 爬升至 3.3V 就绪窗口内 12 路输出无闪光(反复上下电 10 次)。
3. 单条灯带:调光/色温曲线、低亮度台阶感、MOSFET 温升、无可闻噪声、手机高快门拍摄无条纹;示波器测 HCT 输出与 MOS 栅极边沿,核算 NTD5865 开关损耗。
4. 满载:电子负载 12A 连续运行至少 1h,测采样电阻、防反管、端子和功率脊椎温升;再做 15A 短时测试验证铜箔余量。INA237 对钳流表校准并验证 11A 预警/12A 降亮度,但不把该测试当成硬保护验证。
4a. 国产候选料准入:首单额外抽取约 10 只 NTD5865、5 只 SUD50P06 和 5 只 TX4144,核对包装/丝印/批次;抽测关断漏电、指定栅压下导通压降与批次离散性。前 2 片在完成 12A 热测试后,再以 8~12A 代表性动态负载累计老化 ≥24h,期间记录 5V 纹波、MOS/电源温度和失效/漂移。通过后才把这些候选标记为本项目合格料。
5. 关断尖峰:示波器看长线(5m+)灯带关断时漏极电压,要求重复尖峰 **<50V** 且无持续振铃;任一指标超过即重新选 TVS/回路,不得依赖 MOS 雪崩吸收。**另需实测支路短路熔断时间**:人为短接某路 CW/WW 至 GND,记录从短路到保险丝熔断的时间与该期间的母线电压跌落,要求 <1s 且其余通道能在熔断后恢复正常。
6. 干接点、UART/I2C、上电无闪光(反复上下电 10 次)逐一验证。
7. 前 2 片全部通过后再释放其余 3 片投入使用;若出现耐压、温升或供电隔离问题,其余 3 片保持不上电并进入改版评审。

## 12a. 扩展路径:超过 6 条灯带怎么办

**结论:加板,不要试图在单板上加通道。**

8 条 CCT(16 路 PWM)在单块经典 ESP32 上做不成。LEDC 通道数勉强够(16 个,零余量),但**引脚卡死**:WROOM-32E 上"可输出且非启动敏感"的引脚恰好只有 16 个(GPIO 4/5/13/14/16/17/18/19/21/22/23/25/26/27/32/33),16 路 PWM 会全部占满,I2C 与 UART 传感器口一个不剩。剩下的 strapping 脚不能承担 I2C —— I2C 必须挂上拉电阻,而 GPIO12 上电被拉高会令 ESP32 按 1.8V flash 电压启动(**板子无法开机**),GPIO2 被拉高则破坏自动下载。因此单板 8 条的代价是砍掉 INA237 与全部传感器接口,即本设计的全部差异化。

电源侧问题更大:8 条 × 3A = **24A / 576W**,已超过本板正常 12A 预算和 15A 功率脊椎/主保险能力;单块板、单台 300~320W 电源均不能承载,强行集中供电需要重新设计输入端子、保险和整条母线。

**正解**:6 条以上按 4+4 或 6+2 分为两块板并分区供电,架构原样复用、功率分散、可就近安装(省 24V 长线压降)、单板故障只影响一半灯光;新增板与电源按当次报价另算,不沿用旧版的单板成本。HA 中呈现为两个 ESPHome 设备,使用体验无差别。
