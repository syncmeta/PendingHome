## 安装方向(2026-08-07 定稿:端子朝下)

**驱动板三明治整体旋转 180° 安装**:灯带/电源端子边朝下,传感器接口边朝上。
PCB 丝印文字已按此方向预转 180°,挂墙后正读。背板驱动区的 4 个 M3 孔
已按旋转后坐标开孔;底板葫芦孔在板文件的 y137(倒装后位于墙面上部,槽口朝上)。

## 装配(背板自上而下)

```
墙/洞洞板
 └─ 背板(顶部葫芦孔×3 直接上墙,或侧缘 φ5.5 孔挂洞洞板钩)
     ├─ 电源 LRS-350-24(上):底面朝背板,M3 穿腰形槽锁电源底孔,风扇朝外
     ├─ 驱动板三明治(中,端子朝下):底板 → M3×25 铜柱×4 → PCB → 铜柱×4 → 顶板
     │   (底板用 M3×8 螺丝从背板背面锁入最下层铜柱)
     └─ 绕线桩 ×6(下):M3×25 铜柱立在背板上,顶端锁 φ30 圆盘 → 余线绕柱身
```

## 线缆走向(所有线底部出)

- 电源 24V 输出:从电源端子下行(沿侧缘)→ 驱动板下边缘的 24V 输入端子
- 灯带线 ×6:从驱动板下边缘端子出 → 绕线桩区盘绕余长 → 底部离开背板
- 传感器线(Qwiic/UART/干接点,接口现朝上):细线沿三明治两侧的
  **φ3.5 扎带孔对**(每侧 4 组)下行,与主线在绕线区汇合。

## 关键说明

- **挂孔 20mm 网格的理由**:宜家 SKÅDIS 挂钩间距 40mm(20 的倍数 ✓),国产
  五金洞洞板挂钩多为单点悬挂(任意孔可用 ✓),两者通吃。
- **葫芦孔**:大孔 φ9 / 槽宽 4.5,配 M4~M5 半圆头螺丝(头径 ≤8.5)。挂法:
  螺丝留 4mm 间隙 → 大孔套入 → 下滑锁定。
- **电源腰形槽**:LRS-350-24 底面安装孔的官方跨距未逐一核实,故开 20mm 长
  腰形槽 ×4(±8mm 调整量)。**装配时以实物孔位为准**,若仍对不上,以槽内
  M3 + 大垫片压边固定亦可。电源风扇面朝外,前方留 ≥30mm。
- **天线净空**:驱动板右下 ESP32 天线区(悬出板边)——三明治右下角的铜柱
  已按 PCB 孔位避开;背板为亚克力不挡 2.4GHz;**不要在天线区加金属垫圈**。
- **换保险丝**(已确认方案 B):拧下顶板 4 颗螺丝取下顶板,镊子换 Nano2 丝。
- 立创面板免费打样活动(至 2026-08-31)单片 ≤500cm²:两块 120×155(186cm²)
  可拼一张;背板 240×380 = 912cm² 超限,需正常下单(约 ¥40~60,5mm)。
