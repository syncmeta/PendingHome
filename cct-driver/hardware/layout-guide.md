# PCB 布局指导

板框 **100mm(宽)× 150mm(高)**(v14 实测包络自动分区后定稿;115mm 的早期估算装不下实测元件包络),原点左上角,坐标单位 mm。2 层,1oz。
**所有元件顶层**(经济型 SMT 单面焊接);底层仅覆铜与走线。

## 分区(自上而下)

| 区 | y 范围 | 内容 |
|---|---|---|
| 输出端子 | 2–15 | J3–J8 沿上板边一字排开,x 中心 15/29/43/57/71/85(13mm 间距) |
| 支路保险丝 | 16–24 | F2–F7(Nano2 座)各自对齐所属端子正下方 |
| 功率级 ×6 列 | 24–44 | 每列:2× MOSFET(Q)+ 2× SS36B + 2× TVS + 电解 + MLCC,列宽 ~14mm |
| 驱动区 | 44–56 | U6/U7 居中,栅阻/下拉/12 颗指示灯就近 |
| 功率脊椎 | 56–80 | J1 输入(左板边)→ F1 → Q1/Q2 → RS1 → U1(INA237 紧贴 RS1)→ C1–C5 电解排 → D1 |
| 控制区 | 80–113 | 左:buck(U2/L1/D2 环路最小)+ PTC1;中:CH340C/Type-C(下板边)/按键;右:ESP32 |

## 硬性几何约束

1. **ESP32 天线净空**:U4 放右下角,**天线段悬出下板边**(y=115 之外),模组两侧 ≥10mm、正下方全层禁铜。天线区内不放铜柱/螺丝(亚克力外壳同样遵守)。
2. **buck 开关环路最小**:C32/C33(VIN 陶瓷)→ U2 → D2 → GND 回路 <2cm²;L1 紧接 SW;SW 铜面积尽量小;R62(RT)紧贴 U2。
3. **INA237 开尔文采样**:IN+/IN− 从 RS1 焊盘内侧单独引 0.3mm 细线,平行等长,不碰功率铜。
4. **功率脊椎 15A**:J1 → F1 → Q1/Q2 → RS1 → 分配点,双面 ≥20mm 覆铜 + 过孔缝合(≥30 个 0.5mm 过孔)+ 顶层开窗上锡。分配点之后每列支路 ≥3mm。
5. **GND 单点连接**:功率地(MOS 源极/电解负极)与信号地(ESP32/INA237)在 RS1 附近汇合,信号区不承载功率回流。
6. 保险丝座 F2–F7 上方留 ≥8mm 镊子操作空间(即端子与保险丝座之间不放高元件)。
7. 四角 M3 安装孔,中心距板边 5mm;右下角那颗避开天线净空(移到 x=95,y=100)。
8. Type-C(J2)与 XH/Qwiic/KF128(J9/J10/J11)放下板边,插拔方向朝外。
