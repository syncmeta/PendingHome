## 需要展开的几条

### §2 焊盘孔环（危险4 已完全落位）

从 `cct-main-PTH.drl` + `F_Cu.gtl`/`B_Cu.gbl` 逐孔量的全板分布
（323 个金属化孔 × 2 层 = 646 个测量点）：

| 环宽 | 测量点数 | 是什么 |
|---|---|---|
| 0 mm | **4** | J2 的 2 个 0.6mm 定位孔（铜盘 = 钻孔 = 0.6mm），两层各算一次 |
| 0.15 mm | 320 | 156 个 0.3mm 钻孔 / 0.6mm 盘的过孔；U2 焊盘下 4 个 0.3/0.61 散热孔(0.155) |
| ≥0.20 mm | 322 | 81 个 0.4/0.8 过孔、43 个 0.5/1.0 过孔、全部插件焊盘（0.2–0.7mm） |

**全板不存在 0 < 环宽 < 0.15mm 的孔。** 0.15mm ≥ 嘉立创双面板 0.1mm 下限。
危险4 与报告精确对上。

> 警告 96 这个数字**未能逐一对上**——按环宽 <0.2mm 算应是 320 个测量点。
> 猜测是报表每项显示上限 100 行（4+96 正好 100，丝印三项也都正好停在 50）。
> 这不影响判定：该档最坏值 0.15mm 已实测确证。

那 2 个 0.6mm 孔：`net = None`，是 TYPE-C-31-M-12 的外壳定位柱，不导电、不受力。
环宽 0 意味着孔壁镀铜没有锚点、可能在蚀刻时掉一圈——对定位柱无影响。
（order-checklist.md 里「USB 座无铜定位孔」这条历史结论成立。）

### §3 插件焊盘距贴片焊盘

用 Gerber 的真实铜形状逐对量（43 个插件焊盘对 524 个贴片焊盘），4mm 内有贴片盘的
只有 15 个插件脚：

| 距离 | 组合 | 网络 |
|---|---|---|
| 0.000mm ×4 | U2 封装内 4 个 0.3mm 散热孔 ↔ U2.9 散热盘 | 同为 GND，设计如此 |
| 0.180mm ×2 | J2.4 ↔ J2.A1B12 / J2.1 ↔ J2.B1A12 | 同为 GND |
| 0.260mm ×2 | J2 两个定位孔 ↔ J2.A1B12 / B1A12 | 定位孔无网络 |
| 2.245mm ×2 | F1.2 ↔ Q1.3 / F1.4 ↔ Q2.1 | 不同元件，充裕 |
| ≥2.5mm ×5 | J3 各脚 ↔ TP6、J2 pin2/3 ↔ 大盘 | 充裕 |

**结论：所有 <1mm 的组合都发生在同一个元件内部，而且同网络。没有一处是两个不同元件
之间的。** 手工焊 J2/U2 时不存在跨网络搭锡的风险。

> 报告给的 0.53mm 在板上**没量到完全对应的值**（最接近的是 J2 内部的 0.18/0.26mm），
> 说明嘉立创的取样口径和我不同（很可能把部分过孔也算成了插件孔——
> order-checklist.md 里有同样的历史判断）。数值未对上，但结论不受影响。

### §6/§7/§8 丝印三条（你要的抽查，我做的是全查）

**§6 丝印距焊盘——全板 38 个焊盘被丝印压到，来源逐个查明：**

- 36 处是**该焊盘自己封装的丝印**：C1/C2/C3/C4/C5/C16/C18/C20/C22/C24/C26/C35
  （12 只 8mm 电解的外框，各 2 脚）、C14.1/C15.1/C34.1/R10.1（0.06mm 极性点）、
  DZ1.2、LED1.1、TP1.1–TP6.1。
- 2 处是**隔壁封装的丝印**：C36 的外框压到 **D3.1**；C37 的外框压到 **D4.1**。
  （C36/C37 是 22µF 1210，D3/D4 是 SS36B SMB，两者本来就挨着。）
- **我们自己加的板级丝印一处都没碰到焊盘 —— 实测 0 处。** 板级丝印一共 35 个图元：
  8×8mm 白油块（4.20,49.20–12.20,57.20）+ 34 段文字（"cct-driver.local"、
  "CH1–CH6"、"WW/CW/V+"×18、"DC 24V IN MAX 12A"、"I2C 3.3V"、"UART 5V"、
  "SW1-4 DRY"、"5V"、"FUSE 4A-T x6 / MAIN 15A"、"CCT-DRIVER v1.0 2026-08"、"+"、"-"）。
  逐段对全板 571 个焊盘做的距离计算，最近距离全部 >0.15mm。

**而且这条其实连"存在"都算不上：** `F_Silkscreen.gto` 第 21832 行开始是 `%LPC*%`
（清极性），后面 571 个焊盘形状的挖空图元把所有压在焊盘上的丝印**都减掉了**。
嘉立创的检测器显然只看了暗极性图元、忽略了清极性挖空。**实板上不会有一根丝印印在焊盘上。**

**§7 丝印距孔——49 个孔，48 个是过孔**（被 F2–F7、D5/D9/D11/D13/D15/D17/D19/D21/
D23/D25/D27、LED1/LED6/LED11/LED13、C2/C3/C4/C12/C21/C25/C27/C38/C40/C43、
J1/L1/R32/R41/U2/U6/TP1 这些封装自己的外框线扫到）。
**唯一一处是我们的**：板级竖排文字 `"CCT-DRIVER v1.0 2026-08"`（线宽 0.18mm，
x≈1.91–2.81，y≈60.79–72.57）横穿 **H2（M3 安装孔，4.00,65.00，Ø3.2mm）**。
钻孔会把那行字咬掉一个缺口，**纯外观**。真要修就把这行字往下或往左挪 0.6mm。

**§8 丝印线条宽度——这条要更正「封装自带」的说法：**

| 线宽 | 段数 | 归属 |
|---|---|---|
| 0.12mm | 6380 | **182 处位号文字（refdes）** ← 报告给的 0.12mm 就是它 |
| 0.13mm | 586 | 板级文字（"CH1"等以外的那批，thickness=0.13） |
| 0.06mm | 388 | 194 个封装各 2 段的极性点，LCSC 封装自带 |
| 0.10mm | 2 | LED1 封装自带 |
| ≥0.15mm | 其余 | 正常 |

嘉立创丝印最小线宽 0.15mm，低于此会印不清或印不出来。0.06mm 的极性点本来就小到看不见，
无所谓；**0.12mm 的位号文字会发虚**，影响收板后照着位号找元件。纯外观，
**本批放行，建议下一版把位号线宽提到 0.15mm、字高 0.6→0.8mm 一起改**（一次重导 Gerber + 重跑 DFM）。

### §11/§12 Q1 ↔ Q2（元件碰撞 + 元件距元件，同一对）

- Q1 中心 (102.4, 115.6855)，Q2 中心 (95.6, 115.6855)，都是 rot 270 的 TO-252-2。
- 本体（F.CrtYd）：Q1 = x 99.10–105.70，Q2 = x 92.30–98.90，y 均为 111.03–117.14。
- **本体间隙 = 0.200mm**，与报告「元件距元件 0.2mm 危险」数值精确吻合。
  嘉立创的 TO-252 3D 模型比 6.6mm 略大，所以「元件碰撞」判成 0mm。
- 报告截图（元件碰撞那张）里的青色标线正好画在两颗 TO252 中间的缝里，
  下方的 "Q1 F1 Q2" 是丝印位号，F1 只是位号文字恰好在中间，本身离得很远
  （F1 本体 y 122.14–128.86，与 Q1/Q2 本体下缘 y=117.14 相距 5.0mm）。

**电气上没有风险**：Q1/Q2 是并联的同一对 P-MOS，三个脚一一同网
（1 = PMOS_GATE、2 = V24_PROT、3 = V24_FUSED），两个塑封体就算蹭上也不会短路。
焊盘之间实测最近 1.08mm（两片散热盘之间）、1.24mm（Q1.3 ↔ Q2.1），充裕。

**风险是机械的**：DPAK 本体公差 ±0.2mm，最坏情况两个塑封体挤在一起，
可能把其中一颗顶歪、散热盘虚焊。一颗虚焊另一颗仍能带满 12A（SQD50P06 单颗余量足够），
所以不是致命项。**本批放行；下一版建议把中心距从 6.8mm 拉到 ≥7.3mm。
收板后重点看 Q1/Q2 有没有贴歪。**

（报告的「碰撞 警告1」是另一对，全板第二近的 CPL 元件对是 LED9↔R24 = 0.816mm，
其后是 D13↔F4 / D17↔F5 / D21↔F6 / D25↔F7 / D5↔F2 / D9↔F3 / C16↔D8 等一批
0.820mm，**未能确定具体是哪一对**；这个距离档没有任何风险。）

### §14 元件焊脚到孔（贴片焊盘压过孔）— 本次最实的一条

我逐点查了 `F_Mask.gts`：**有 27 个过孔的孔口落在贴片焊盘自己的阻焊开窗里，是露铜的。**
它们本身没有被单独开窗（KiCad 确实做了盖油），但焊盘的开窗盖住了它们的位置，
阻焊是并集，所以还是露出来了。

### §17/§18 PIN脚内边界 / PIN脚右边界 —— 未能确认

这两项比对的是**嘉立创自家 3D 模型的引脚外形 vs 焊盘**。我拿不到他们的 3D 模型，

J11、Q3/Q6），所以**无法逐个复现，具体是哪 8 个 / 哪 6 个引脚，未能确认。**

我能确证的是：**本板 31 个元件封装全部是 easyeda2kicad 从 LCSC 原厂封装转换来的**
（每个 `.kicad_mod` 首行都是 `easyeda2kicad:`，内含 `LCSC Part` 属性），
**我们没有手改过任何一个焊盘**。自制的只有 `TestPoint_Pad_D1.5mm` 和
`MountingHole_3.2mm_M3` 两个，都不是贴片元件、都不在 CPL 里。
也就是说：如果真有引脚超出焊盘，那是**嘉立创自己的 3D 模型和自己的封装库对不上**，

**这是推断，不是确认。**
